03 - RQ2: SHAP Feature Importance¶

Notebook version: v20 -- 2026-08-02

  • Apply TreeExplainer SHAP to the best RQ1 model
  • Rank features by mean |SHAP value|
  • Cross-check against permutation importance
  • Report ALE curves for the top features as a complementary, engineer-facing deliverable

Why SHAP over TreeInterpreter: TreeInterpreter's Saabas-style decomposition is provably inconsistent (Lundberg, Erion, & Lee, 2018) -- it can lower a feature's assigned importance even when that feature's true impact increases. TreeExplainer was built to fix exactly this, and also (unlike TreeInterpreter) covers both Random Forest and XGBoost with the same exact algorithm. See docs/synopsis.docx, "Solution to RQ2" for the full rationale, including the parallel discussion of why LIME was set aside (src/feature_selection.py docstring covers PCA).

Step 2: Permutation importance cross-check¶

In [4]:
from sklearn.inspection import permutation_importance

# Permutation importance MUST be evaluated on genuinely held-out data --
# rq1_best_tree (used for SHAP above) was refit on 100% of the data, so
# evaluating permutation importance with it on X/y would silently reuse
# training data. rq1_best_tree_holdout was trained ONLY on train_idx
# specifically so this evaluation is genuine. Using the training-data model
# here previously produced permutation importances of ~1e-17 for every
# feature (floating-point noise) -- a real, not cosmetic, methodological bug.
holdout_model = load_model("rq1_best_tree_holdout")
holdout_split = load_json("rq1_holdout_split")
X_test_ho = X.iloc[holdout_split["test_idx"]]
y_test_ho = y.iloc[holdout_split["test_idx"]]

perm = permutation_importance(
    holdout_model, X_test_ho, y_test_ho, n_repeats=10, random_state=42, scoring='roc_auc', n_jobs=-1
)
perm_importance = pd.Series(perm.importances_mean, index=X.columns).sort_values(ascending=False)
print(f"Top 10 features by permutation importance (evaluated on {len(X_test_ho)} held-out wafers):")
print(perm_importance.head(10))

overlap = set(top_features) & set(perm_importance.index[:10])
print(f"\nOverlap with SHAP top-10: {len(overlap)}/10")

Step 3: ALE curves for the top features (complementary deliverable)¶

SHAP tells you which sensors matter; ALE tells you which direction is bad -- e.g. "fail probability rises sharply once this sensor exceeds X". Used instead of Partial Dependence Plots because ALE stays unbiased under correlated features (Apley & Zhu, 2020), unlike PDP, which assumes feature independence.
